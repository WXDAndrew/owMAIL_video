## Notas Importantes

1. **Frame local vs global**: Dentro de un `<Sequence>`, `useCurrentFrame()` retorna el frame LOCAL (desde 0), NO el global. Todas las animaciones deben usar frames relativos al inicio de la secuencia.

2. **Phone mockup**: 440x800px para formato 9:16, con border-radius 32, box-shadow prominent.

3. **Textos grandes**: En formato 9:16, usar fonts de 64-80px para títulos, 28-36px para body.

4. **Animaciones profesionales**: Usar `spring({ damping: 30, stiffness: 100 })` para transiciones suaves y naturales.
